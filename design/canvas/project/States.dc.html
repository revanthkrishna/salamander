add note · off
icon-only (comment glyph, name in the tooltip) with the secondary button’s own hover/press fills — it only turns yellow once add mode is on. hover or focus reveals the “keep on” switch beside it; the button itself never changes size.
add note · on
add mode is on for a single note (plain click), so the button is yellow — but the switch segment stays neutral until the switch itself is turned on. saving the note ends add mode.
add note · locked
the switch is on, so both halves are yellow and the switch stays visible: add mode continues note after note until it is turned off.
